# Wine quality dataset

## What the tables contain

The dataset has two tables, one for red wines and one for white wines. Each row is one wine. The columns are laboratory measurements plus one quality column. Exercise 1 trains a model to predict that quality column from the measurements.

## The quality score

Quality is a sensory score given by tasters. It is not computed from residual sugar, alcohol, or any other laboratory column. A later exercise asks a deployed model to estimate that score from the measurements. This assistant only explains the notes. It does not estimate a quality score, and it must say so when someone asks for one.

## What this assistant is for

Ask it what a column means, how two columns differ, or what the notes say about an example wine. Answers have to come from these notes. A measurement that is not written here is not a fact the assistant may invent.
